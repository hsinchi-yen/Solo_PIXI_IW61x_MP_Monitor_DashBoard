# 操作手冊 — IW61x Solo PIXI 產測看板

網址：`http://10.20.31.40:8003`（8004 也可以；瀏覽不用登入）。左下角可切換 **中文／English** 和 **淺色／深色**。

## 1. 看數字

**篩選列**（右上）：時間範圍（全部／今天／本週／本月／自訂）＋工單。一開始顯示**最新一張工單**。

**儀表板**
| 數字 | 意思 |
|---|---|
| 良率（最後結果） | 每台機器**最後一次**測試的結果。大數字，綠 ≥ 98%、黃 95–98%、紅 < 95% |
| 一次通過／任一次通過 | 第一次就通過的比例；測了幾次之中有通過就算 |
| 測試台數 | 以 MAC1 計；下方小字是**測試次數**（含重測與沒有 MAC 的測試） |
| PASS／FAIL／STOP | 台數（依最後結果）；下方小字是次數 |
| 重測率 | 測試超過一次的台數比例；下方是重測後通過的台數 |
| 超出規格 | 有量測值超出規格的測試項目數 |

圖表：良率趨勢（三條線）、每小時測試量、失敗步驟前 5 名（次數／台數／重測後通過）、每月台數。

**工單**：每張工單的三種良率、測試次數、沒有 MAC 的次數、重測率；「✨ AI 報告」開啟該工單的報告。

**失敗清單**：FAIL／STOP 每一筆；可搜尋、只看 FAIL 或 STOP；「下載」原始 log 需要登入。

**量測分析**
- **規格檢查**：所有有規格的 IW611 測試項目，最需要注意的在最上面（超出規格 → Cpk 低 → 餘裕小）。點一列，下方顯示分布圖，紅色虛線是規格。
  - Cpk ≥ 1.33 良好；1.0–1.33 偏緊；< 1.0 製程能力不足。
  - 餘裕：最差的量測值離規格多遠，負的表示超出規格。
- **BT／Wi-Fi**：各模式的功率、EVM、頻偏、BER／PER 平均與最差值。
- **其他**：測試時間分布、晶振校正（XTAL_REG）、Wi-Fi 頻偏每日變化、重測最多的機台。

**失敗分析**：失敗步驟與類別的統計、錯誤訊息明細。

## 2. AI 品質報告

在「工單」頁按「✨ AI 報告」，或側欄「AI 報告（最新工單）」。
- 數字全部由系統計算，AI 只負責寫總評、3 個發現、3 個建議；中文、英文兩版都有。
- 每次上傳完成後和每天 18:00 會自動產生；也可以按「重新產生」（約 1 分鐘）。
- 可以「複製」「下載 Markdown」「和上一份比較」，也可以在下方追問（只根據這張工單的資料回答）。

## 3. 上傳 log（需要登入：上傳者或管理者）

1. 側欄「上傳 Log」→ 登入。
2. 拖入檔案：**工單 zip**（各站資料夾 30、40… 裡放 `Log_all.txt`），或已切好的單筆檔案（`YYYYMMDD_HHMMSS_MAC1_MAC2_RESULT.txt`，散檔或 zip）。系統會自動切檔並列出各站筆數、台數、PASS／FAIL／STOP。
3. **AI 助理**會問工單號和工單計畫生產數，直接打字回答即可（例如「5101-260715003，計畫 200 台」）。AI 不在線時會自動改成表單。
4. 看下方的檢查結果：❌ 必須修正；⚠ 確認無誤後勾選「我已確認」；ℹ 只是提醒。
5. 按「確認上傳」，畫面會顯示進度。已經在資料庫的測試會自動略過，重傳是安全的。
6. 上傳錯了：在下方「上傳紀錄」按「撤銷」，只會刪除那一批新增的資料，計畫數也會還原。上傳者只能看到、撤銷自己的批次。

桌面版上傳程式仍可使用（直接連資料庫，資料最多 5 分鐘後出現在看板，或按右上「立即更新」）。

## 4. 管理者

管理者帳號由伺服器 `.env` 設定（`ADMIN_USER`／`ADMIN_PASS`）。

| 頁面 | 用途 |
|---|---|
| 資料庫維護 | 依篩選條件瀏覽紀錄、下載原始 log、刪除單筆或整個範圍（會再確認一次）、重新解析失敗欄位 |
| 計畫數對齊 | 設定每張工單的計畫生產數；Aligned 良率 = PASS ÷ max(實測台數, 計畫數) |
| 帳號管理 | 建立上傳者帳號、停用／啟用、重設密碼；查看帳號異動紀錄與登入紀錄 |

所有刪除、上傳、撤銷、計畫數修改、帳號異動都會記錄操作人與時間。
